製作流程：從Unity Asset Store載入飛機模型，並利用方塊物體製作障礙物。飛機的程式包括操作與障礙物碰撞偵測，障礙物則是偵測飛機位置是否通過障礙物來播放通過音效與加分。另外，還有生成障礙物的程式，將障礙物生成於隨機位置。最後將畫面投影到手機上操作。

操作：透過方向鍵或將鼠標移到特定位置並長按滑鼠左鍵或長按螢幕特定位置來操作飛機飛行方向，當飛機通過障礙物時會加1分並播放音效。若機身碰到障礙物，遊戲即結束。
